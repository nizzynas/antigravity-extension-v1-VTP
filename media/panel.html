        Voice Commands
        ▾
      
      

        
          

            Say
            What happens
          

        
        
          

            hey antigravity
            Starts recording & appends to your prompt buffer.
          

          

            send it / send the prompt
            Sends directly into the chat — no click needed.
          

          

            enhance this prompt
            A local Ollama model rewrites it. Approve / Reject / Try Again inline.
          

          

            approve / reject / try again
            Voice-control the enhancement review.
          

          

            clean it up / scrub that
            Cleans the buffer in place — silent, no preview.
          

          

            clean up and review
            Cleans + shows preview. Approve / Reject / Try Again inline.
          

          

            Auto-clean (silent, runs before every send)
          

          

            Filler words and immediate repeats are stripped automatically.
              Heavy noise triggers a local cleanup if Ollama is installed.
          

          

            cancel / clear that
            Discards the transcript buffer.
          

          

            Pause & Resume
          

          

            pause / mute
            Mutes mic immediately. Buffer preserved.
          

          

            resume / I'm back
            Wakes back up exactly where you left off.
